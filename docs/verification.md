# Проверка перед публикацией

Проверка черновика: 31 октября 2026 года.

- Право переноса материалов и схем подтверждено владельцем задачи. Другие репозитории при подготовке не изменялись.
- Проверены локальные пути и якоря Markdown. Из 25 проверенных внешних адресов пять вернули `403`: `chatgpt.com`, `claude.ai`, страница поддерживаемых стран ChatGPT, тарифы и условия OpenAI. Код `403` сам по себе не означает отсутствие страницы; их нужно проверить в браузере. Адреса GitHub Pages ожидают публикации.
- `@earendil-works/pi-coding-agent` версии 1.4.0 указывает Node.js `>=22.19.0`, `sitectl` версии 0.6.0 — `>=22.17`; пакет `pi-cliproxyapi-provider` найден в npm. Установка и работа этих версий здесь не выполнялись. Настройки клиентов сверены с документацией [провайдера Pi](https://github.com/0xRichardH/pi-cliproxyapi-provider), [Codex](https://developers.openai.com/codex/config-advanced) и [Claude Code](https://code.claude.com/docs/en/gateways).
- Команды `sitectl`, установка расширения и слушающий `127.0.0.1:8317` установщик сверены с публичными репозиториями; синтаксис примера Caddy проверен командой `caddy validate`. Документация CLIProxyAPI подтверждает пути панели и API v0/v8. Защита маршрутов, SSH-туннель, сервер, входы, клиенты, названия всех элементов EasyCLIProxyAPI и оплата не проверялись в живой системе; проверь их до использования. Список management-маршрутов нужно сверить с установленной версией прокси.
- HTML и JSON схем пересозданы и прошли `archify deliver`. `archify visual-check` прошёл для каждой схемы в четырёх размерах окна с найденным Chromium; визуальная оценка скриншотов остаётся открытой. В headless-браузере проверены переключение всех глав, темы и масштабирования, ошибок JavaScript не обнаружено. Ранние `*.visual-check.json` в репозитории отражают предыдущий пропуск проверки, а не новый запуск во временном каталоге. Веб-шрифт загружается с Google Fonts, доступен запасной системный шрифт.
- Для GitHub Pages подготовлен `.github/workflows/pages.yml`: при обновлении `main` он собирает три HTML-файла и публикует их как Pages artifact. GitHub Pages включён по подтверждению пользователя через настройку **Source: GitHub Actions**; окружение `github-pages` разрешает публикацию из `main`, HTTPS включён. Локально проверены формирование каталога публикации и workflow через `actionlint`; workflow и URL ещё не проверены на GitHub, потому что публикация не выполнялась.
- Gitleaks 8.30.0 проверил отслеживаемые и неигнорируемые новые файлы: совпадений с правилами поиска секретов нет. Поиск частных доменов, названий систем и адресов электронной почты в тексте совпадений не нашёл. OCR трёх PNG также не обнаружил заданные признаки секретов, адресов и частных систем; проверенные поля метаданных PNG пусты. Автоматические проверки ограничены и не гарантируют отсутствия секретов и персональных данных, особенно на изображениях: повторить проверку перед публикацией.
- Страницы и материалы на тему OAuth прочитаны в пределах доступности источников; юридическую применимость к конкретной конфигурации определяет пользователь по действующим условиям провайдера.

**Статус: не готово к публикации** до завершения открытых проверок в `openspec/changes/create-ai-access-guide/tasks.md`.
