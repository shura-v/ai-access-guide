# Вход в подписки

## Условия и риски

CLIProxyAPI технически поддерживает OAuth для Codex и Claude Code, но это само по себе не разрешение провайдера на применение подписки в стороннем приложении. [Anthropic описывает ограничения OAuth](https://code.claude.com/docs/en/legal-and-compliance): использование OAuth предназначено для собственных приложений, а сторонним разработчикам запрещено маршрутизировать запросы пользователей через учётные данные тарифов Claude.ai. Для сторонних интеграций предлагается API с отдельной оплатой. Применимость к твоему сценарию проверь до входа; блокировка и потеря доступа возможны.

Для ChatGPT проверь действующие [условия Sign in with ChatGPT](https://openai.com/policies/sign-in-with-chatgpt-terms/) и условия своей подписки. Доступность стороннего сценария и конкретной модели не гарантируется.

## Google Antigravity

[Условия Google Antigravity, пункт 6](https://antigravity.google/terms/), прямо запрещают использовать сторонние программы и сервисы для доступа к Antigravity, включая сценарии с Antigravity OAuth. Google предупреждает о возможной приостановке или блокировке аккаунтов Antigravity и Gemini CLI. Это не разрешённый Google способ подключения подписки; техническая поддержка прокси запрет не отменяет. Для корпоративных аккаунтов действуют отдельные условия — уточни их у администратора.

[CLIProxyAPI документирует](https://help.router-for.me/configuration/provider/antigravity) вход Antigravity по OAuth. Техническая последовательность: аккаунт Google с доступом к Antigravity → вход Antigravity в установленной версии прокси → выбор доступной модели в клиенте → [проверка ответа](check.md). Для выбора модели смотри список клиента после настройки по [инструкции клиента](clients.md); её точный идентификатор зависит от версии прокси. Названия пунктов в панели и их наличие зависят от версии. Для локального CLI документация указывает `./cli-proxy-api --antigravity-login` и callback на порту `51121`; эта команда и работа панели для Antigravity здесь не проверены. Доступность модели в самом Antigravity не гарантирует её работу через прокси. Не передавай пароль, OAuth-токены или callback URL третьим лицам; для VPS защищай панель SSH-туннелем, как описано ниже.

Для использования на условиях Google выбирай модели непосредственно в Antigravity. Ознакомься с [тарифами, квотами и доступностью](accounts.md#google-ai-и-antigravity) до оплаты.

## Вход при локальном запуске

При условии, что выбранный способ допускается провайдером, в EasyCLIProxyAPI открой **OAuth → Claude** и заверши вход в браузере. Клиентский ключ скопируй в **Home → API Access → First key**. Локальный вход Codex через EasyCLIProxyAPI отдельно не проверен; используй инструкции установленной версии и проверь условия OpenAI.

## Вход через VPS

Панель не должна быть доступна через публичный адрес. Открой SSH-туннель, подставив свой SSH-адрес сервера:

```bash
ssh -N -L 8317:127.0.0.1:8317 USER@VPS
```

Оставь терминал открытым. Если порт 8317 занят, используй слева другой порт, например `-L 18317:127.0.0.1:8317`. Тогда в адресах панели и её API ниже используй `18317` вместо `8317`. При условии, что выбранный способ допускается провайдером:

1. Открой `http://127.0.0.1:8317/management.html` на своём компьютере. Войди с **ключом управления**, который отличается от клиентского ключа. В настройках панели адрес API укажи как `http://127.0.0.1:8317`, если он запрашивается.
2. В разделе OAuth выбери Codex или Anthropic, начни вход и открой выданный URL в браузере.
3. Заверши вход в аккаунт. В режиме удалённого браузера, если открылся недоступный адрес `localhost`, скопируй **полный** адрес из строки браузера в поле Callback URL панели и отправь его.
4. Дождись подтверждения авторизации и проверь состояние аккаунта в панели. Если вход истёк, повтори процедуру.

Callback URL содержит код авторизации: не отправляй его в чат и не записывай в документы. OAuth-токены хранятся на машине с прокси; защищай её как устройство с доступом к аккаунту.

Далее: [подключение клиентов](clients.md).
