# Локальный CLIProxyAPI

Локальный прокси подходит для одного компьютера. Он должен работать во время использования клиента; сетевой доступ к провайдеру и условия его использования по-прежнему важны.

1. Скачай [EasyCLIProxyAPI](https://github.com/router-for-me/EasyCLIProxyAPI/releases) для своей ОС и проверь инструкции проекта.
2. В приложении установи ядро через **Version Management**, затем запусти его через **Home** и проверь статус `Running`.
3. Проверь адрес и порт в **Home → API Access**; типичный адрес — `http://127.0.0.1:8317`. Там же скопируй **First key** для клиента. Используй только доверенную машину и не открывай порт в сеть без защиты.
4. Прочитай [ограничения и инструкции локального входа](login.md#вход-при-локальном-запуске), затем настрой клиента по [инструкции](clients.md). Для Pi и Codex используй `http://127.0.0.1:8317/v1`, для Claude Code — `http://127.0.0.1:8317`; порт возьми из приложения.

Клиентский ключ из **API Access** отличается от ключа управления и OAuth-токенов. Не передавай его в чат и не сохраняй в репозитории.
