# Доступ к AI-сервисам

Практический маршрут: подписка ChatGPT или Claude → CLIProxyAPI → Pi, Claude Code или Codex → проверка. Прокси можно запустить на своём сервере или локально.

> **Перед началом:** техническая совместимость не означает, что провайдер разрешает любой способ использования подписки. Условия, доступность по странам и цены меняются; проверь их перед оплатой и подключением. Сторонний прокси получает доступ к учётным данным и запросам.

## Маршрут

1. [Регистрация и оплата](docs/accounts.md) — условия, ограничения и безопасность.
2. [Прокси на VPS](docs/vps.md) — сервер, HTTPS и ключи. Для локального запуска см. [альтернативу](docs/local.md).
3. [Вход в подписки](docs/login.md) — авторизация в прокси и ограничения провайдеров.
4. [Подключение клиентов](docs/clients.md) — Pi, Claude Code и Codex.
5. [Проверка и диагностика](docs/check.md) — проверка маршрута и типичных ошибок.

## Архитектура прокси

[![Архитектура прокси](docs/diagrams/ai-proxy.png)](https://shura-v.github.io/ai-access-guide/)

[Вход в подписку](https://shura-v.github.io/ai-access-guide/login.html) · [Маршрут запроса](https://shura-v.github.io/ai-access-guide/request.html)

Интерактивные схемы будут доступны после публикации GitHub Pages. Локальные HTML и JSON находятся в `docs/diagrams/`; для просмотра открой HTML-файл в браузере. Интерфейс просмотра схем — на английском языке; для веб-шрифта требуется соединение с Google Fonts, при его отсутствии используется запасной шрифт.

Схемы показывают технический маршрут, а не разрешение провайдера. Поддержка моделей и доступность сети зависят от условий сервиса.

В примерах `cpa.example.com` — адрес твоего прокси. Используй свои значения и не публикуй ключи, токены и callback URL.
